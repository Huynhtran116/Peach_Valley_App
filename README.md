# 🏨 Peach Valley Hotel Management System (Mobile App)

Đây là ứng dụng di động đặt phòng và quản lý khách sạn được phát triển trong khuôn khổ Đồ án Tốt nghiệp ngành Công nghệ Thông tin tại Trường Đại học Công Thương TP.HCM (HUIT).

## 📱 Công nghệ sử dụng
- **Mobile App:** Flutter (Dart)
- **Backend API:** Laravel (PHP)
- **Database:** MySQL
- **Deployment & Container:** Railway, Docker
- **Payment Gateway:** VNPAY / ZaloPay

## ✨ Tính năng nổi bật
- Tìm kiếm và đặt phòng trực tuyến.
- Tích hợp thanh toán qua cổng VNPAY/ZaloPay.
- Đặt dịch vụ (ăn uống, spa, giải trí) ngay trên App.
- Quản lý lịch sử đặt phòng và kho khuyến mãi.
- Chức năng Đăng ký / Đăng nhập / Đổi mật khẩu.
- Xem chi tiết tiện nghi phòng và đánh giá của khách hàng.
